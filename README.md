# 🚀 技術スタック・プロジェクト構成

本プロジェクトは、Web版およびモバイル版での展開を想定し、開発効率とパフォーマンスを重視したモダンな技術構成を採用しました。

---

## 💡 技術スタックの概要

| 区分 | 技術 | 採用理由・目的 |
| :--- | :--- | :--- |
| **フロントエンド** | **Next.js** (React/TypeScript) | **Web/モバイル展開の想定**と、**既存のReact開発経験**を活かした開発コスト・工数削減のため。 |
| **モバイル** | React Native (TypeScript) | Web版と同じくReactベースで、効率的にモバイルアプリを展開するため。 |
| **バックエンド** | Next.js (API Routes) | Next.jsの機能を利用し、フロントエンドと統合して開発を進めるため。 |
| **状態管理** | Zustand | シンプルで軽量な状態管理ライブラリ。必要に応じて導入。 |
| **データベース** | **MySQL** | 安定性と信頼性の高いリレーショナルデータベース。 |
| **ORM** | **Prisma** | TypeScriptの型システムを活用し、SQL文を直接書かずに安全にDB操作を行うため。**実行前にDBエラーを検出可能**。 |
| **デプロイ** | AWS | ドメイン取得まで含めたインフラ環境として選定。 |

---

## 🛠️ 開発・テスト環境

| 項目 | 技術 | 目的・実装内容 |
| :--- | :--- | :--- |
| **ローカルテスト** | husky | コミット前、プッシュ前にテストを自動実行し、コード品質を保つ。 |
| **リモートテスト** | GitHub Actions | プッシュ時やプルリクエスト時にテストを自動実行し、デプロイ前の品質を担保する。 |
| **UI実装** | **Dnd-Kit** | タスクの**ドラッグ＆ドロップ機能**を実装するために採用（使用経験あり）。 |
| **認証機能** | **Firebase** (Authentication) | 認証、DB連携、APIがセットになっており、**実装コストを大幅に抑制**するため。 |

## 📂 Next.js プロジェクトディレクトリ構造 (App Router)

Next.jsのApp Routerを採用し、フロントエンド（React UI）とバックエンド（API Routes）を統合して管理しています。

my-app/ ├─ app/ ← フロント部分 (React UI) │ ├─ page.tsx ← ホームページ │ ├─ login/page.tsx ← ログイン画面 │ └─ dashboard/ ← ログイン後画面 │ ├─ app/api/ ← バックエンド (API Routes) │ ├─ auth/route.ts ← 認証関連 (ログイン状態確認など) │ └─ tasks/route.ts ← タスク追加・削除処理 │ ├─ lib/ │ └─ prisma.ts ← Prismaクライアントの共通初期化 │ ├─ prisma/ │ └─ schema.prisma ← Prismaスキーマ (DB定義) │ ├─ public/ ← 画像や静的ファイル │ ├─ .env ← 環境変数 (MySQL接続URLなど) ├─ next.config.js ├─ package.json └─ tsconfig.json

## ✅ タスク管理機能の実装詳細

本プロジェクトで実現するタスクのCRUD（作成・読み取り・更新・削除）機能と、リマインダー機能の仕様です。

### 1. タスクの基本属性

* **タイトル**: 必須項目（大文字表示）
* **詳細**: オプション（小文字表示）、表示/非表示の切り替え機能あり
* **完了ステータス**: タスクの完了状態を管理
* **進捗バー**: タスクの進捗状況を視覚的に表示

### 2. 入れ子構造（階層管理）

タスクの親子関係は、**JSON階層**と**パス管理**（例：親A/子/孫）の組み合わせで管理します。

> **注記:** パス管理により、子を別の親に移動した際、子と孫以下のすべてのタスクのパスを再帰的に更新する処理を実装します。

### 3. リマインダー機能 (※いずれか1つのみ実装)

以下のうち、いずれか一つのリマインダー機能を実装します。

* **A. 期日**: 特定の**日付と時間**を指定
* **B. 繰り返し (定期)**: **毎日**、**毎週**など、定期的な繰り返し設定
* **C. 繰り返し (リセット)**: タスク完了時に期日を**特定期間後にリセット**する設定
